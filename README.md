# Neptune

Pet project which used to be called KoboldGL.
Can be considered a series of modules for a game engine that never came to be.

- Pluto: Utility Functions
- Charon: Compression, Hashing and Ciphers
- Triton: Imaging
- Sedna: Data-Driven SDL Scene Graph
- Ceres: glTF Structures
